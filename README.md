# Elliesam Daycare Management System

A desktop-based daycare management system built with Python and Tkinter to help Ellisam Daycare manage children, parents, staff, attendance, payments, and daily activities.

##  Problem Statement

Elliesam Daycare needs an organized way to manage information about children, parents and guardians, staff, attendance, payments, and daily activities. Managing these records manually can make it difficult to keep information organized and quickly access the required records.

##  Solution

The Ellisam Daycare Management System provides a centralized desktop application where authorized staff can manage daycare records in one place. The system will allow administrators and caregivers to manage children's information, track attendance, record daily activities, manage payments, and maintain other important daycare records.


## Features
- User authentication
- Child management
- Parent/guardian management
- Staff management
- Attendance tracking
- Daily activity records
- Payment management
- Pickup and drop-off records
- Reports

## User Roles

### Administrator
The administrator can:

- Manage children's information
- Manage parents' and guardians' information
- Manage staff information
- Manage payments and fee records
- View daily daycare reports

### Caregiver

The caregiver can:

- View children under their care
- Record children's attendance
- Record meals and activities
- Record nap/rest times
- Add notes about each child's day
- Record children's drop-off and pick-up

## Technologies
- Python - Backend
- Tkinter - User interface
- MongoDB - Database
- PyMongo - Database connection with the backend
- Git & GitHub - Source control
